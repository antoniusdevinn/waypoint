Live fares & how the schedule pick works

Live fares come from Google Flights (pulled through SerpApi) by the small server.js included with this app (your API secret stays on the server, never in the browser). Start it with your free key and open the address it prints — the chip up top turns green when live mode is on. Without the server running (e.g. opened as a plain file), Waypoint still works using distance-based estimates plus the one-click search links to Google Flights, Skyscanner, Trip.com, Booking, Agoda and Traveloka.

Cheapest fares by site. The Compare Trip / Traveloka / Agoda button checks live prices across booking sites for the cheapest flight each way and shows every site's price, with the cheapest highlighted. Tap Use cheapest to put that total into the fare box. The two directions are priced as separate one-way tickets, so the site total is out + return — and it is compared against a proper round-trip ticket from live fares, since a round-trip ticket is sometimes cheaper than two one-ways. Prices come from PriceWin, which reads the sites' public pages at search time — no key needed, but reconfirm the final fare on the booking site before paying.

Auto-refresh. Tick Auto-refresh live prices and Waypoint re-checks live fares and site prices every 30 minutes while the page is open, for destinations you already pulled. It only runs while the tab is visible, and the Updated time next to it shows the last refresh. It does not run when the page is closed.

Land together, return together. After you pull live fares for a destination, Waypoint reads every flight's real arrival time and searches for the combination — one flight per friend — that lands the group in the tightest window, and whose return flights also depart close together. The Cheapest ↔ Land together slider tilts the pick: all the way left favours the lowest total fare, all the way right favours the smallest gaps between arrivals and between return departures. The recommendation updates as you drag.

Quota & accuracy. The free SerpApi plan includes a limited number of searches per month; results are live Google Flights data, so most routes return real prices and times. If you run out of quota, searches will fail until it resets or you upgrade your SerpApi plan. Always reconfirm the final fare on the airline or booking site before paying.
